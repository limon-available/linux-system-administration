## Practical Tasks

### 1. Introduction to Linux Terminal

Practiced using the Linux command-line interface (CLI) to interact with the operating system.

Basic commands:

```bash
whoami
hostname
pwd
date
```

### 2. Understanding Linux System Information

Learned how to identify the current user, hostname, working directory, and system date.

```bash
whoami
hostname
pwd
date
```

### 3. Basic Command-Line Navigation

Practiced navigating the Linux filesystem and understanding directory locations.

```bash
pwd
ls
cd
cd ~
cd ..
```

### 4. Working with Files and Directories

Practiced basic filesystem operations.

```bash
mkdir test
touch example.txt
ls
```

### 5. Getting Help with Linux Commands

Learned how to access built-in documentation and command help.

```bash
man ls
ls --help
```

## Important Commands Practiced

| Command    | Purpose                           |
| ---------- | --------------------------------- |
| `whoami`   | Display current username          |
| `hostname` | Display system hostname           |
| `pwd`      | Display current working directory |
| `date`     | Display system date and time      |
| `ls`       | List files and directories        |
| `cd`       | Change directory                  |
| `mkdir`    | Create directories                |
| `touch`    | Create empty files                |
| `man`      | Read command manuals              |
| `--help`   | Display command help              |
